# Dashboard screenshots

`dashboard-overview.jpg` and `dashboard-prediction.jpg` are Chromium captures of the running application using synthetic demo data.
They are captured by `scripts/check_browser.py` after the API is ready and the page has loaded. The prediction screenshot is taken after a successful request to the trained model.

To reproduce them, start the API and run:

```powershell
python -m pip install -e ".[browser]"
python -m playwright install chromium
python scripts/check_browser.py
```

Captures are saved in `browser-results/`. GitHub Actions also uploads them as an artifact.
The PNG files in this folder are architecture and result figures generated by `scripts/plot_results.py` from the saved reference artifacts.
